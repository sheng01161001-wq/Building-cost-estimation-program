# 建築估算程式(Building Estimator)

把建築師給的 CAD 圖(另存成 DXF)或向量 PDF 丟進網頁,自動估算各工種數量:

- **結構**:混凝土(樓板、梁、柱、RC 牆)、模板、鋼筋
- **泥作**:砌磚(含紅磚塊數)、內外牆粉刷打底、地坪打底
- **磁磚**:地磚、浴廁 / 廚房壁磚、外牆磚(含片數)
- **油漆**:內牆、天花板
- **外牆(立面)**:立面面積扣門窗、欄杆,依材料分區(二丁掛、小口磚、石材…)

最後把全部樓層 × 層數、四向立面加總,匯出 Excel。

**直接使用:** 開啟 GitHub Pages 網址(見下方「部署」)。圖檔只在瀏覽器裡處理,不會上傳到任何伺服器。

---

## 使用步驟

1. **匯入圖檔**
   - DWG 請先在 AutoCAD 用「另存新檔 → DXF」(任何版本都可以)。
   - PDF 需為 CAD 直接輸出的向量 PDF,並輸入出圖比例(例如 1:100)。PDF 目前是試用功能。
2. **選擇範圍**
   - 「平面圖」模式:點偵測到的圖名(例如「三層平面圖」)自動框選,或按「手動框選」在圖上拖曳。
   - 「立面圖」模式:框選一個立面(一棟的一面)。
3. **確認圖層對應**:程式依圖層名稱自動判斷 RC 牆、磚牆、柱、門、窗、欄杆,請確認牆厚。
4. **輸入參數**:樓高、版厚、天花板高、相同樓層數等,按「計算」。
5. **加入專案總表**:每算完一層 / 一個立面就加入;到「專案總表」匯出 Excel。

### 整棟計算建議流程

- 平面:B3、B2、B1、1F、夾層、標準層(設定相同樓層數)、屋突層,各算一次。
- 立面:四向立面各算一次;屋頂框架等不算外牆的部分,用「框選材料分區」選「不計」扣除。
- 專案有立面資料時,外牆數量改用立面結果,不再用平面「周長 × 樓高」。

## 計算方式

| 項目 | 算法 |
|---|---|
| 空間面積、周長 | 依圖上空間名稱文字(客廳、浴廁、陽台…)自動圍出封閉範圍 |
| 牆長 | 牆圖層線段總長 ÷ 2(去除牆頭短線);門窗上下方的牆面補回 |
| 柱 | 柱圖層上的封閉多邊形 |
| 梁 | 有梁線圖層就用梁線長度;沒有時以樓地板面積 × 係數(預設 0.3 m/m²)估算 |
| 鋼筋 | 混凝土量 × 含筋率(版 90、梁 160、柱 200、牆 100 kg/m³,可調) |
| 紅磚 | 1/2B 64 塊/m²、1B 128 塊/m²(可調) |
| 磁磚片數 | 面積 ÷ 單片面積;外牆磚含灰縫 |
| 立面 | 外牆輪廓內扣除門窗、欄杆;有填充線的區塊依填充圖層歸類材料 |

### 每個案子不同的設定

- **隔間做法**:在「圖層對應」為每個牆圖層選 RC 牆、紅磚、白磚 / 輕質磚、輕隔間(乾式),並填牆厚。
  - 紅磚:算砌磚面積與塊數(1/2B 64 塊/m²、1B 128 塊/m²)
  - 白磚:算面積、塊數(依規格,預設 60×20 cm)、黏著劑
  - 輕隔間:算面積、板材張數(雙面 × 層數)、C 型立柱長度、隔音岩棉
  - 白磚與輕隔間牆面不算水泥粉刷,改算「批土整平」
- **磁磚規格**:「本案設定」分頁設定各類空間(浴廁、廚房、陽台、居室、公共空間…)的地磚、壁磚規格與壁磚高度;個別空間要不同規格(例如主浴),在「空間明細」單獨改。
- **專案檔**:右上「儲存專案檔」會把樓層、立面、圖層對應與所有設定存成一個 `.json` 檔,同事用「開啟專案檔」就能接著做、用同一套設定。「新案」會清空專案並把設定恢復預設。

## 目前不包含

- 基礎與地下結構(筏基、地梁、連續壁)
- 樓梯、女兒牆、屋頂防水隔熱、浴廁防水
- 門窗樘數清單(目前只用於扣除面積)

數量為估算,請以施工圖核對。

## 部署(GitHub Pages)

Settings → Pages → Source 選 `Deploy from a branch`,Branch 選 `main`、資料夾 `/ (root)`,儲存。
約一分鐘後網址為:`https://sheng01161001-wq.github.io/Building-cost-estimation-program/`

## 檔案結構

```
index.html        可直接使用的單一網頁(已內嵌計算核心)
src/engine.js     計算核心:DXF 解析、房間偵測、數量計算、立面分析、Excel 產生
src/index.html    介面原始檔(開發用,引用 engine.js)
```

修改 `src/` 之後,重新產生根目錄的 `index.html`:把 `src/index.html` 裡的 `<script src="engine.js"></script>` 換成 `engine.js` 的內容即可。
