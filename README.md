# 小棒槌 建築估算程式

## 1. 這個程式是做什麼的

把建築師給的 CAD 圖(另存成 DXF)或向量 PDF 丟進網頁,自動估算整棟建築各工種的材料數量,最後匯出 Excel。功能類似把 CAD 圖交給估算公司算數量。

可以估算的項目:

| 工種 | 項目 |
|---|---|
| 結構 | 混凝土(樓板、梁、柱、RC 牆)、模板、鋼筋 |
| 泥作 | 紅磚(面積與塊數)、白磚 / 輕質磚、輕隔間(板材、立柱、岩棉)、內外牆粉刷打底、地坪打底與粉光 |
| 磁磚 | 地磚、浴廁 / 廚房壁磚、外牆磚(含片數) |
| 石材 | 外牆石材(依立面分區) |
| 油漆 | 內牆、天花板、批土(白磚 / 輕隔間面)、外牆塗料 |
| 其他 | 外牆門窗開口面積、欄杆 / 透空面積 |

運作方式:

- **平面圖**:依圖層名稱自動判斷 RC 牆、磚牆、柱、門、窗、欄杆;再依圖上的空間名稱文字(客廳、浴廁、陽台…)自動圍出每個空間,算出面積與周長,依空間類型套用地坪、壁磚、油漆。
- **立面圖**:自動圍出外牆輪廓,扣除門窗與欄杆,依填充線或使用者框選的區塊分材料(二丁掛、小口磚、石材…)。
- **專案總表**:各樓層 × 相同樓層數、四向立面加總;有立面資料時,外牆數量改用立面結果。

所有計算都在使用者自己的瀏覽器裡進行,圖檔不會上傳到任何伺服器。

## 2. 檔案說明

```
index.html              可直接使用的網頁(單一檔案,已內嵌 src/engine.js)
src/engine.js           計算核心(純 JavaScript,瀏覽器與 Node.js 都能執行)
src/index.html          介面原始檔(開發用,以 <script src="engine.js"> 引用計算核心)
assets/icon-512.png     程式圖示(512×512,含「小棒槌 / 建築估算程式」字樣)
assets/apple-touch-icon.png  手機主畫面圖示(180×180)
assets/icon.svg         程式圖示向量檔
assets/mark.svg         小圖示(網頁左上角、瀏覽器分頁用)
README.md               本說明
```

`src/engine.js` 內各段負責的工作:

| 區段 | 函式 | 負責 |
|---|---|---|
| 1. 文字解碼 | `decodeBytes`、`cleanMText` | DXF 文字解碼(UTF-8 / Big5 碼頁、`\U+XXXX`)、清除 MTEXT 格式碼 |
| 2. DXF 解析 | `parseDXF` | 以位元組串流讀取 ASCII DXF(支援大型檔案):圖層、圖塊、實體 |
| 3. 圖元展開 | `flattenDXF`、`parseHatchLoops` | 展開巢狀圖塊(INSERT)、OCS 座標、弧線離散化、HATCH 邊界 |
| 4. 圖層角色 | `guessRole`、`ROLES` | 依圖層名稱判斷 RC 牆、紅磚、白磚、輕隔間、柱、梁、門、窗、欄杆 |
| 5. 空間類型 | `ROOM_TYPES`、`roomTypeOf`、`defaultFinishes`、`defaultParams` | 空間名稱 → 類型(浴廁、廚房、陽台、居室、公共、機房);預設裝修與係數 |
| 6. 平面分析 | `analyzeRegion` 等 | 點陣化牆線、門洞封閉、由空間名稱填色圍出房間、輪廓追蹤求面積 / 周長、外圍周長、牆長、柱、門窗偵測與歸屬 |
| 7. 數量計算 | `computeQuantities` | 結構、泥作、磁磚、油漆各項數量與損耗 |
| 8. Excel 產生 | `buildXLSX` | 不用外部函式庫產生 .xlsx(ZIP + XML) |
| 9. 立面分析 | `analyzeElevation`、`elevationItems`、`guessElevRole` | 外牆輪廓、開口 / 欄杆辨識、材料分區(填充線 + 使用者框選)、外牆材料數量 |
| 其他 | `findPlanTitles`、`planBoxNearTitle`、`floorRepeat`、`detectUnit` | 偵測圖名並自動框選範圍、「九至十二層」→ ×4、判斷圖面單位(mm / cm / m) |

`src/index.html` 負責介面:檔案匯入(DXF、PDF)、圖面檢視(縮放、平移、框選)、圖層對應表、參數輸入、結果分頁(本層數量、空間明細、本案設定、專案總表)、專案檔儲存 / 開啟、Excel 匯出。

## 3. 安裝與執行

不需要安裝。

**方式一:線上使用(分享給同事)**
開啟 GitHub Pages 網址:<https://sheng01161001-wq.github.io/Building-cost-estimation-program/>
(儲存庫 Settings → Pages → Branch 選 `main`、資料夾 `/ (root)` 才會生效。)

**方式二:在自己電腦使用**
解壓縮後,用 Chrome 或 Edge 開啟 `index.html`。除了讀 PDF 需要連網(會從 cdnjs 載入 pdf.js),其餘功能都可以離線使用。

**準備圖檔**
DWG 請在 AutoCAD 用「另存新檔 → DXF」,格式選 **ASCII**(不要選 Binary),版本選 AutoCAD 2013 以後。版本太舊(如 R12)會遺失填充線。

**操作流程**
1. 匯入 DXF(沒有圖檔可先按「載入示範平面圖」)。
2. 平面圖模式:點偵測到的圖名(例如「三層平面圖」)自動框選,或「手動框選」。
3. 確認圖層對應(牆種、隔間做法、牆厚),填樓高、版厚、天花板高、相同樓層數 → 「計算這一層」→「加入專案總表」。每種不同的樓層各做一次。
4. 立面圖模式:四向立面各算一次;屋頂框架等不算外牆的部分,用「框選材料分區」選「不計」扣除;不同材料的區塊也用框選指定。
5. 「本案設定」分頁調整各類空間的磁磚規格、壁磚高度、隔間材料規格、含筋率、損耗率;個別空間可在「空間明細」單獨改。
6. 「專案總表」→「匯出 Excel」。「儲存專案檔」可把整個案子(樓層、立面、圖層對應、設定)存成 `.json`,給同事接著做。

**修改程式**
改 `src/engine.js` 或 `src/index.html` 後,重新產生根目錄的 `index.html`:把 `src/index.html` 裡的 `<script src="engine.js"></script>` 換成 `<script>`+ `engine.js` 內容 +`</script>`。計算核心也可以在 Node.js 直接測試:

```js
const QE = require('./src/engine.js');
const doc = QE.parseDXF(new Uint8Array(require('fs').readFileSync('plan.dxf')));
const F = QE.flattenDXF(doc);
```

## 4. 目前進度與尚未完成的部分

**已完成並以實際圖檔(CN25010 集合住宅建照圖)驗證**

- DXF 讀取:整套圖約 55 萬條線、225 個圖層,讀取約數秒。
- 平面:二層平面自動圍出 27 個空間,樓地板約 271 m²,與圖上面積計算(中心線)差異約 1~2%。示範圖(已知尺寸)面積誤差在 1% 以內。
- 立面:四向立面外牆淨面積合計約 2,700 m²,與平面周長 × 樓高推算相符。
- 隔間做法(紅磚 / 白磚 / 輕隔間)、各案磁磚規格、個別空間規格、專案檔、Excel 匯出、圖示。

**準確度有限、需人工確認的部分**

- 梁:建築平面圖通常沒有梁線,改以樓地板面積 × 係數(預設 0.3 m/m²)估算;要準確須匯入結構平面圖並把梁線圖層設成「梁(線)」。
- 鋼筋:以含筋率(kg/m³)估算,不是依配筋表計算。
- 沒有寫空間名稱的區域(管道間、未標示的陽台)不計入裝修;開放陽台、露台若沒有欄杆線封閉,會列在警告裡。
- 門窗必須是圖塊才會被偵測;炸開成散線的門窗不會扣除開口。門窗高度用統一設定值(門 210、窗 150、窗台 90 cm),沒有讀門窗表。
- 立面是投影面積,凹凸側面須用「凹凸補正 %」補;材料分區只有畫填充線的區塊能自動判斷,其餘要手動框選。
- 壁磚高度用設定值,沒有讀室內展開圖。
